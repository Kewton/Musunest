# core/ — 店頭が正本を持つ境界

このディレクトリは**店頭（プラットフォーム側）が正本を持つ**部分である。
テンプレートを使う工場（CommandAgent）は、ここを**変えてはいけない**。

## なぜ変えてはいけないか

テンプレートは店頭が配る契約であって、工場が作る成果物ではない（企画書 13 章 Template as Contract）。
core/ を工場が書き換えられると、同じテンプレートから作られたアプリどうしで
「店頭が保証する部分」が食い違う。契約が契約でなくなる。

## 工場ができること

- **読む**ことはできる。core/ は境界の説明を含む。
- **変える**ことはできない。変えてよいのは `app-zone/` だけである。

## 何を置くか

M1 では境界の宣言だけを置く。実装は店頭がここへ入れる。

変えてよいかの正本は `../template.json` である（`zones[].factoryMutable`）。
