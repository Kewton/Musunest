# app-zone/ — 工場が L3/L4 のコードを置く場所

ここはテンプレートの中で、**工場（CommandAgent）だけが変えてよい唯一の領域**である。
正本は `../template.json` の `zones[].factoryMutable`。

## 制約

- **M1 では店頭はここを動かさない。** 店頭が app-zone/ を実行するのは M1 の範囲外である。
- **SSR にしない。** host は SPA シェル＋Static Assets で配る（CLAUDE.md「小さく保つ」）。
  app-zone/ のコードはブラウザで動き、サーバ側では実行しない。
- 店頭が持つ `core/`・`sdk/` は読む・使うだけで、書き換えない。

## 何を置くか

M1 では境界の宣言だけを置く。動く雛形は作らない（実行時の依存を足さない）。
