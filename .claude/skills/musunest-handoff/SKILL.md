# musunest-handoff

窓口の**進行中の状態**を、セッションをまたいで引き継ぐ。置き場所は `workspace/mem/`（この機械だけ。git で追跡しない）。

- **読む**は、SessionStart フック（`.claude/settings.local.json`）が README を自動で文脈に入れる。この skill の「読む」は、その中身を**確かめて片付ける**手順である。手動でも呼べる
- **書く**は窓口が判断して行う。自動にはしない

## 0. 何を書き、何を書かないか

**書くのは GitHub に置き場所が無いものだけ**である。

| 種類 | 例 |
|---|---|
| 返事待ち | 所有者に聞いたまま答えをもらっていない質問 |
| git の外の状態 | staging のインスタンス、Release、動いたままの tmux、人が消す worktree |
| 未記録の決定 | 会話で決まり、まだ Issue にも文書にも書いていないこと（**書いたら消す**） |
| 次の一手 | 次にやることと、その順番 |

**書かないもの**：merge した PR・Issue の中身（GitHub が正本）、決まりと罠（`docs/parallel-development.md` か `CLAUDE.md` に PR で足す）。

## 1. README の形

```
workspace/mem/
├── README.md     ← ルール＋「いま」＋インデックス（20 行まで）
├── items/        ← 1 行で書けない項目の詳細だけ（行を消すときに一緒に消す）
├── requests/     ← 進行中の Issue の依頼文だけ（Issue が閉じたら消す）
└── plans/        ← 二重登録ガードの記録だけ（cmate-issue-authoring の receipt）
```

- **「いま」**：いま走っている長い操作を 1〜2 行。無ければ「なし」
- **インデックス**：`| 種類 | 項目 | 消す条件 | 確かめ方 |` の表。**どの行にも消す条件と確かめ方を書く**。確かめ方は 1 行のコマンドか「—」

## 2. 読む（再開）

呼ぶとき：セッションの始め、PC やセッションが落ちたあと、会話が要約されたあと、所有者に頼まれたとき。

1. `workspace/mem/README.md` を読む（自動で読み込まれていなければ開く）
2. **「いま」の操作が終わったかを調べる**。管理への依頼なら `commandmate capture musubi --instance command-code --pane --tail 80` と、`gh pr list` / `gh issue view` で結末を取り直す
3. インデックスの行ごとに**確かめ方を実行し、消す条件を満たした行を消す**（`items/` の対応するファイルも消す）
4. `git worktree list` と、各 worktree の `git status --short` で、未コミットの変更と残っている worktree を調べる
5. 所有者に報告する：途中だった操作の結末・返事待ちの質問（そのまま示し直す）・次の一手・消した行

## 3. 書く（チェックポイント）

**状態が変わる前に 1 行書く。** 書いてから動く。

| とき | 書くこと |
|---|---|
| 長い操作・バックグラウンドの操作を**始める前**（管理への依頼、staging での計測、画面テストなど） | 「いま」を書き換える。**結末の取り直し方**（コマンド）も書く |
| その操作が終わったとき | 「いま」を「なし」に戻す |
| 所有者に質問したとき／答えをもらったとき | 返事待ちの行を足す／消す |
| git の外の状態を変えたとき | 行を足す／消す |
| 会話で何かが決まったとき | 未記録の行を足し、**Issue のコメントか文書に書いたら消す** |
| セッションを終えるとき | 全体を見直す |

守ること：

- **追記ではなく書き換える**
- **インデックスは 20 行まで。** 超えたら、GitHub（Issue）に置き場所を作るよう所有者に提案する
- 罠を見つけたら README に書かず、手順書に PR で足す（PR が merge されるまでは「次の一手」の 1 行にする）
- 秘密（staging のオリジン・ホスト名・Account ID・トークン）を書かない

## 4. やってはいけないこと

- 盤面の写し（merge した PR の一覧、Issue の本文）を README に書く
- 消す条件の無い行を足す
- `workspace/mem/` を git に足す（`.gitignore` に入っている）
