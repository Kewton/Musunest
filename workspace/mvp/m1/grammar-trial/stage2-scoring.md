## 2. rubric（要件 → 採点）

役割の見つけ方：**ref で指される側で、文字列の項目を持つ entity**がメンバー。そのメンバーを ref で指していて、**要件の選択肢の表示名の集合**（A：料理／飲み物／道具・まだ／用意できた、B：ゴミ出し／公園の掃除／夜回り・予定／済み）と一致する enum を 2 つ持つ entity が主役。見つからなければ「**人が判定**」に回す。

| 要件 | 判定の仕方（名前に依存しない） | 機械／人 |
|---|---|---|
| メンバーと主役を登録できる | 両方の entity に create の操作がある（`kind` 省略は create） | 機械 |
| 主役の項目（名前・種類・人・数／日付） | 役割の見つけ方そのもの（型と選択肢の表示名） | 機械（表示名が違えば人） |
| A：数は 1 以上 | 数の項目を 0 にしたレコードで検査が落ち、1 で通る | 機械 |
| 登録したときの状態（A「まだ」・B「予定」） | 状態の enum の `default` が、その表示名の鍵 | 機械 |
| 状態を進めるボタンは、進める前の行にだけ | `update` で状態を進める先に `set` する操作があり、`when` が「前」の行で真、「後」の行で偽 | 機械 |
| 状態ごとの列のボード | `board` が主役を状態の enum で列にする | 機械 |
| 種類と人で絞り込み | 主役の `list` の `filters` に、種類の enum と人の ref が両方ある | 機械 |
| 人ごとの数が**見られる** | メンバーの count の計算が、m1 2 件・m2 1 件の入力で m1＝2 を返し、**かつ**メンバーの表か一覧の `show` に入っている（v2。§4） | 機械 |
| B：今日の当番に印 | ボードの `highlight` が指す計算が、今日で真・昨日と明日で偽 | 機械 |
| B：回数の少ない順（**書けない**） | 人の回数を `ranking`（降順）で並べていない。**書けないと申告したか**は宣言の外（AI の返答）にある | 機械（逆向きの検出）＋**人（申告の有無）** |
| 画面の文言・項目の表示名・一覧の `show` の中身 | 見ていない | 人（`06` §2.4 の段 2） |

## 4. 落とせなかったもの・分かったこと

1. **rubric v1 は「見られる」を見落とした**（`A-violates-hidden`）。計算が正しい値を返すことと、画面に出ることは別である。v2 で「メンバーの表か一覧の `show` に入っている」を足した。**「見られる」「出す」と書いた要件は、値と表示の 2 つで採点する**
2. **選択肢の表示名に頼る役割の見つけ方は、言い換えの正解を機械で拾えない**（`A-correct-relabel`）。落としはしない（「人が判定」に回る）が、10 × 5 回で言い換えが多ければ人の採点が膨らむ
3. **構造の別解の合否が、事前に決まっていない**（`A-correct-genre-entity`）。`06` §4.3「期待値を生成結果に合わせて後から変えない」に従うなら、第 4 段の前に決める必要がある
4. **書けない要件の申告は宣言の外に出る。** rubric が見られるのは「逆向きで書いていないか」までで、「書けないと言ったか」は AI の返答を読まないと分からない
5. **静的チェックは思ったより強い。** メンバーの表を落とした例は `UI_REF_TARGET_NOT_SHOWN`・`UI_ACTION_NOT_REACHABLE` で静的に落ちた（rubric の出番が無かった）。無い語彙の発明も `SHAPE_KEY_UNKNOWN` で落ちる
6. **rubric が見ていない段がある**：配信・保存・拒否・画面（`06` §4.3 の段 2）と、操作を続けたときの値（段 3 の `scenario.json`）。今回の rubric は「宣言 1 本を評価器に通して、1 件ずつの答えを見る」までである

## 5. 決定（2026-10-09 所有者）

1. **依頼文に「選択肢の表示名は要件の言葉のまま」と書く。** 言い換えた別解（`A-correct-relabel`）は、依頼に従っていないので不合格とする
2. **構造の別解（種類を entity にする）は不合格とする。** 要件が固定の選択肢を挙げているなら enum が正解である
3. **出力の形を固定する。** 宣言 1 本と「書けなかった要件」の欄（要件の文と理由）を返させる

→ rubric が「役割が見つからない」を返したものは、1・2 により**不合格**として数える（人の判定に回さない）。
