### 疎通で分かったこと（手順の故障）

- **採点の前に `pnpm install` が要る。** `main` に依存（#211 の `ajv`）が入ったあと、手元で install しないまま `pnpm build` すると失敗する（窓口が踏んだ）。採点の手順は **`pnpm install --frozen-lockfile` → `pnpm build` → `spec:check`** にする（`06` §5 の「ビルドを忘れると古い語彙で判定される」に足す）
- **`spec:check` は、誤りが 0 件のとき何も出さずに exit 0 で終わる。** 記録には終了コードを書く
- **新しいセッションの作り方は「試行専用の worktree ＋ そこに新しいインスタンス」で回った**（`06` §5 の未確認の点）。既存のセッションを落とさずに済む。1 回ごとに worktree を作り直せば、前の回の会話は持ち越さない
- **worktree を登録する `commandmate sync` は、管理の auto-yes を初期化する。** 試行と並行して管理に依頼を送るときは、送る前に入れ直す
- 試行のあと、worktree は消したが、**試行用のセッション（tmux）は窓口の権限では止められなかった**。次の段の前に人が止める
