## 3. 止まる条件（今回）

- 既存の採点器の分母の補正と、予定・実行・未実行の照合が無い → 正式な基準を測らない（診断まで）
- #418 の内容の確認で、所属・`options` を省いた応答が通る／旧形式へ落ちる経路が残る → N1b に進まない
- 比較条件が固定できない（dist と文書と採点の指紋・判定の構成・締切の意味・予算が記録に残らない）→ 変更に進まない
- 統合候補の独立レビューに「直さないと誤る」指摘が残る → merge しない（`05` §3）
- Plan で止める口が無い／(b) の凍結の規則・組の版が記録に無い → Build の基準を測らない（Build が成功した本に偏るため）
- 評価セットの入口・採点定義・独立点検が揃っていない → 診断と仮説更新までとし、回帰の合否や成績の確定に使わない
