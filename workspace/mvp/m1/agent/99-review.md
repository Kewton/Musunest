### 2.1 R2-4 を独立の Issue にした理由

- **正しさの不具合**である：受入の試験で、合格でない版を合格（`full`）と判定しうる。設計の直し（役割 ID・結び付け）を待たずに直すべきもの
- 直すファイル（走らせる部分と終わりの判定、それぞれの試験）が、役割 ID と確かめ方の Issue と重ならない。並列ですぐに直せる
- Codex の推奨の 3 本の分け方（試験の範囲・役割と入力の契約 → 結び付けと評価の方法 → 停止・版の整合・判定と予算）は保ち、R2-4 だけを先に切り出した（全部で 4 本）
